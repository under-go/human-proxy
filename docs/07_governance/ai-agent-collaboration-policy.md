# AI Agent Collaboration Policy

## 1. 기본 운영
- 모든 작업은 티켓 템플릿으로 시작
- 목표/범위/리스크/테스트 계획을 명시

## 2. PR 정책
- AI Agent PR은 단일 승인제로 운영
- 단, 필수 체크리스트 미충족 시 머지 금지

## 3. 필수 체크리스트
- 영향 모듈 명시
- 데이터 마이그레이션 여부
- 보안 영향
- 테스트 증거 링크

## 4. 위험 변경 규칙
- 결제/원장/권한/보안 변경은 자동 라벨링
- 확장 회귀 파이프라인 강제 실행
