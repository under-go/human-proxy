# Content Tone and Copy Guidelines

## 1. 기본 톤
- 사용자에게 설명할 때는 `짧고 분명한 실무 문장`을 사용한다.
- 기능 자랑보다 `지금 해야 할 행동`을 먼저 말한다.
- 문장은 구어체에 가깝게 쓰되, 가벼운 농담/과장 표현은 피한다.

## 2. 문장 구조 규칙
- 상태 문구: `현재 상태 + 의미 + 다음 행동`
- 오류 문구: `무엇이 문제인지 + 어떻게 해결하는지`
- 안내 문구: `핵심 요약 + 상세 링크`

## 3. 역할별 카피 초점
- AI/오너: 빠른 연동, 운영 가시성, 검토/승인 행동
- 작업자: 합격 기준 명확성, 제출 품질, 정산 예측 가능성

## 4. 금액/기한 표기
- KRW는 쉼표 포함(`₩31,000`)
- 일시는 KST 기준으로 표기

## 5. 권장/금지 표현

### 권장
- `지금 처리할 작업부터 확인하세요.`
- `기준을 확인한 뒤 제출하세요.`
- `승인된 건만 정산됩니다.`

### 금지
- `물리적 제약을 돌파하는 혁신`
- `차세대 패러다임`
- `완벽한 자동화`

## 6. CTA 작성 규칙
- 버튼은 동사형으로 작성한다.
  - 예: `의뢰 시작하기`, `검토함 열기`, `작업 수락`, `정산 보기`
- 같은 화면에 유사 의미 CTA를 중복 배치하지 않는다.
