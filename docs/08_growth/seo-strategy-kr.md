# SEO Strategy KR

## 1. 목표
한국 검색 채널(네이버/구글)에서 신뢰성 높은 유입을 확보한다.

## 2. 기술 전략
- Next.js SSR/ISR
- sitemap/robots 자동 생성
- 구조화 데이터(Organization, FAQPage, HowTo)

## 3. 콘텐츠 전략
- 한국어 중심 랜딩 페이지
- 정책/수수료/환불/분쟁 설명 페이지 강화
- 작업 사례와 가이드 콘텐츠 축적

## 4. 측정 지표
- 비브랜드 유입
- 핵심 키워드 순위
- 랜딩→가입 전환율
