# LEO Strategy for LLM

## 1. 목표
LLM 기반 검색/요약 결과에서 Human Proxy의 정책/기능 정보가 정확히 인용되게 한다.

## 2. 실행 항목
- `llms.txt` 제공
- 정책 문서의 구조화(사실/정책/예시 분리)
- API 문서의 기계가독 예시 강화
- 문서 버전/수정일 명시

## 3. 품질 기준
- LLM이 금액/정산/분쟁 정책을 오인용하지 않도록 문장 단순화
- FAQ와 공식 문서 간 내용 일치
