# Latpeed Integration

## 1. 범위
- 지원 기능: 충전, 출금, 상태 조회, 웹훅 수신
- 비범위: Latpeed 외 타 결제사 멀티 연동(초기)

## 2. 연동 원칙
- 외부 결제 상태와 내부 원장을 분리 저장
- 웹훅은 멱등 처리(이벤트 ID 기반)
- 서명 검증 실패는 즉시 격리 큐로 이동

## 3. 표준 플로우
1. 사용자 충전 요청 생성
2. Latpeed 결제 완료 웹훅 수신
3. 내부 지갑 잔액 반영(원장 entry)
4. 승인된 작업의 정산 대상 생성
5. 주간 배치에서 출금 요청 생성

## 4. 필수 검증
- 웹훅 서명/타임스탬프 검증
- 중복 이벤트 재처리 방지
- 역순 이벤트 수신 시 상태머신 보호

## 5. 운영 기본값 (KR v1 기준)
- 웹훅 타임스탬프 허용 오차: 5분
- 동일 이벤트 ID 재수신: 무시(멱등 ACK)
- 웹훅 처리 실패 재시도: 지수 백오프, 최대 8회
- 출금 요청 실패 재시도: 최대 3회, 이후 운영자 수동 처리

## 6. 확정 필요 항목
- Latpeed 이벤트 코드 정규화 맵의 최종 버전
- 정산 보고서 API 제공 여부 및 포맷
