# Project Charter

## 1. 미션
AI가 단독으로 수행하기 어려운 현실 작업을 사람에게 안전하게 위임하고, 결과를 검증 가능한 형태로 회수하는 **신뢰형 Human Proxy 인프라**를 구축한다.

## 2. 제품 정의
- 서비스명: Human Proxy
- 핵심 고객: AI를 운영하는 개인/팀(의뢰자), 과업 수행자(작업자)
- 핵심 가치:
  - AI 도입자: 표준 API로 사람 작업을 호출하고 결과를 승인/정산 가능
  - 작업자: 투명한 보수와 일정한 정산 주기로 안정적 수익 확보

## 3. KR v1 기본 전략
- 시장: 한국 우선
- 언어: `ko-KR` 기본, `en` 확장 슬롯 선반영
- 결제: Latpeed(충전/출금) + 플랫폼 내부 예치 원장
- 출시: 신뢰우선 제한출시

## 4. 설계 원칙
- 원장 정합성 > 기능 출시 속도
- 모듈 경계 명확화(모듈러 모놀리스 + 이벤트 확장)
- 정책/약관/수수료의 투명한 표시
- 모든 핵심 플로우는 재시도 가능하고 멱등해야 함

## 5. MVP 포함 범위
- API Key 기반 AI 인증
- 작업 등록(프롬프트/기대결과/보수/기한)
- 작업 수락/수행/결과 제출(텍스트, 이미지)
- AI 검토/승인/반려
- 예치, 수수료 차감, 주 1회 정산 배치
- 분쟁 등록/지급 보류/운영자 판정

## 6. MVP 제외 범위
- 다국가 통화/실시간 환전
- 고급 자동중재 AI
- 다중 PG 동시 오케스트레이션
- 완전 자동 법무/세무 처리

## 7. 성공 기준
- 작업 완료율과 승인율이 목표 임계치 상회
- 정산 정확도 100%(원장-외부 지급 정합)
- 고위험 보안 취약점 0건 상태 유지
- 핵심 E2E 시나리오 지속 통과

## 8. 핵심 리스크
- 결제/원장 불일치
- 악성 작업 및 정책 위반 작업
- 분쟁 처리 지연에 따른 신뢰 저하
- AI Agent 자동화 작업의 품질 편차

## 9. 비기능 목표
- 99.9% API 가용성(핵심 경로)
- p95 API 응답 500ms 이내(조회), 1.5s 이내(등록)
- 감사로그 100% 수집 및 추적 가능
