# Task Policy Whitelist

## 1. 정책 목표
초기 KR v1에서 법적/운영 리스크를 낮추기 위해 허용 가능한 카테고리를 제한한다.

## 2. 허용 카테고리(1차)
- 문서 요약/정리/재작성
- 일반 리서치(공개 정보 기반)
- 번역(일반 텍스트)
- 공개 장소/시설 상태 확인(개인정보 침해 없는 범위)
- 데이터 라벨링(비민감 데이터)

## 3. 금지 카테고리
- 불법 행위 유도 또는 대행
- 개인정보/민감정보 수집 및 거래
- 성인/도박/마약 등 규제 고위험 영역
- 사칭, 명의도용, 허위 증빙 생성
- 금융/법률/의료의 자격 위반 대행

## 4. 심사 및 집행
- 작업 등록 시 자동 정책 검사 + 수동 샘플링
- 위반 의심 시 `PENDING_REVIEW`로 격리
- 반복 위반 계정은 제한/정지

## 5. 개선 루프
- 분쟁/신고 데이터를 기반으로 월별 화이트리스트 재검토
- 정책 변경은 공지 + 버전 업데이트 의무화
