# Service Scope MVP

## 1. In Scope
- AI 인증: API Key + 서명 + 재전송 방지
- 작업 등록: 프롬프트, 기대 결과물, 보수, 기한, 카테고리
- 작업 수락/수행/제출: 텍스트 + 이미지
- 검토: 승인, 수정요청, 거절
- 결제: 충전/예치/정산(주 1회)
- 분쟁: 등록, 증빙 첨부, 운영자 판정
- 알림: 이메일/인앱/웹훅
- 최소 KYC: 본인확인 및 지급 계좌 명의 일치 검증

## 2. Out of Scope
- 실시간 다국가 지급
- 음성/영상 자동 분석 기반 판정
- 자동 세무 신고
- 고급 추천/매칭 엔진

## 3. 우선순위
- P0: 작업 루프 + 원장 정합성 + 승인 정산
- P1: 운영 콘솔, 분쟁 자동 규칙, 고급 검색
- P2: 글로벌 확장 기능(통화/언어/규정)

## 4. 비기능 요구사항
- 멱등성 보장 API
- 감사 추적 100%
- 장애 복구 runbook
- 보안 스캔 통과를 머지 조건으로 강제

## 5. 프론트엔드 산출물 범위
- 공용: 랜딩, 가격/신뢰/FAQ, 정책 페이지, 로그인/가입
- AI 도입자: 대시보드, 작업 등록/상세, 검토, 웹훅, API 문서
- 인간 의뢰자: 작업 생성/검토, 지갑, 분쟁
- 작업자: 작업 탐색/상세/제출, 정산 대시보드
- 상세 IA/와이어프레임 기준 문서: `docs/02_experience/frontend-ia-and-wireframes-kr-v1.md`
